Write or paste a C program and run Forester on it. Clang and Forester are compiled to WebAssembly and run in your browser, so your code never leaves your computer. The first run downloads the analyser (about 27 MB, cached afterwards). Use __VERIFIER_nondet_int() for unknown input: Forester follows both outcomes of every condition that depends on it.

program.cCtrl+Enter to run
$ forester program.c
not run yet
Press “Run Forester”. Locations in the output are clickable.

Good to know

  • Forester ends with The program is SAFE or with the first error it finds: an invalid dereference, an invalid free, garbage detected (memory that can no longer be reached: a leak), or a failed __VERIFIER_assert. The note before an error is the instruction of Forester's intermediate code that failed.
  • Forester analyses a whole program starting from main, for a 32-bit target. It assumes that malloc succeeds. It supports pointers between heap nodes well, but not structures on the stack whose address is taken, pointer arithmetic, or most of the C library.
  • This is Forester's last version (2020) with a current version of its front-end and small patches for clang's output; see the main page. If a construct is not supported, Forester says not implemented.
  • Some correct programs are beyond Forester's abstraction: it then reports a false alarm or does not finish. Stop cancels the analysis.
